### Passo 2: Configuração do Modelo Base (Llama 3)

Nesta célula, vamos carregar o modelo de forma otimizada (quantizado em 4-bits) para economizar memória da sua GPU no SageMaker. Você precisará de um *Token* do HuggingFace (é gratuito, basta criar uma conta lá).

```python
# Célula 2: Carregamento do LLM
import time
import os
from langchain_huggingface import HuggingFacePipeline
from transformers import AutoModelForCausalLM, AutoTokenizer, pipeline, BitsAndBytesConfig

# Insira seu token do HuggingFace aqui
os.environ["HUGGINGFACEHUB_API_TOKEN"] = "SEU_TOKEN_AQUI"

model_id = "meta-llama/Meta-Llama-3-8B-Instruct" # Troque por 70B no teste final

# Configuração para rodar de forma leve na GPU (Quantização 4-bit)
quantization_config = BitsAndBytesConfig(load_in_4bit=True)

print("Carregando modelo (isso pode levar alguns minutos)...")
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    quantization_config=quantization_config,
    device_map="auto" # Usa a GPU da AWS automaticamente
)

# Pipeline de geração com Temperatura 0.0 (foco em lógica, sem alucinação)
text_pipeline = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=1024,
    temperature=0.0,
    return_full_text=False
)

llm = HuggingFacePipeline(pipeline=text_pipeline)
print("Modelo carregado e pronto para uso!")

```

### Passo 3: O Teste Monolítico (Grupo Controle)

Vamos enviar um problema de negócio complexo para o modelo resolver sozinho em um único *prompt*.

```python
# Célula 3: Arquitetura Monolítica
tarefa_corporativa = """
Analise o seguinte cenário corporativo: 
A empresa X teve uma queda de 15% na receita no último trimestre. 
Os custos operacionais subiram 5% devido ao aumento de preços de fornecedores de TI.
O setor de vendas perdeu 3 funcionários chave.
Tarefa: Forneça um plano de ação de 3 etapas para reverter a queda de receita, 
considerando contenção de custos e reestruturação da equipe.
"""

print("--- INICIANDO TESTE MONOLÍTICO ---")
start_time_mono = time.time()

# O modelo tenta resolver tudo de uma vez
resposta_monolitica = llm.invoke(tarefa_corporativa)

end_time_mono = time.time()
latencia_mono = end_time_mono - start_time_mono

print(f"\n[Latência Monolítica]: {latencia_mono:.2f} segundos")
print(f"[Resposta]:\n{resposta_monolitica}")

```

### Passo 4: O Teste Multi-Agente (Grupo Experimental com CrewAI)

Aqui, o mesmo modelo atua em 3 "personas" diferentes. Veja como a **Complexidade de Implementação (LoC - Linhas de Código)** aumenta consideravelmente.

```python
# Célula 4: Arquitetura Multi-Agente
from crewai import Agent, Task, Crew, Process

print("--- INICIANDO TESTE MULTI-AGENTE ---")

# 1. Criação dos Agentes (Personas)
analista_financeiro = Agent(
    role='Analista Financeiro Sênior',
    goal='Analisar cortes de custos em TI e eficiência operacional',
    backstory='Você é um especialista em reestruturação financeira de empresas.',
    verbose=True,
    allow_delegation=False,
    llm=llm
)

gestor_rh = Agent(
    role='Gestor de Recursos Humanos',
    goal='Reestruturar a equipe de vendas após a perda de funcionários chave',
    backstory='Você é especialista em contratação rápida e retenção de talentos.',
    verbose=True,
    allow_delegation=False,
    llm=llm
)

estrategista_chefe = Agent(
    role='Diretor de Operações (COO)',
    goal='Unir as análises financeiras e de RH em um plano de ação final de 3 etapas',
    backstory='Você toma decisões finais e consolida planos corporativos.',
    verbose=True,
    allow_delegation=False,
    llm=llm
)

# 2. Definição das Tarefas
tarefa_financas = Task(
    description='A empresa perdeu 15% de receita e os custos de TI subiram 5%. Crie uma estratégia de contenção.',
    expected_output='Um relatório focado em corte de custos.',
    agent=analista_financeiro
)

tarefa_rh = Task(
    description='O setor de vendas perdeu 3 funcionários. Proponha uma solução para não impactar mais as vendas.',
    expected_output='Um plano de reestruturação de equipe.',
    agent=gestor_rh
)

tarefa_final = Task(
    description='Leia os relatórios de Finanças e RH e crie o plano de ação final de 3 etapas para a diretoria.',
    expected_output='Plano de ação final formatado em 3 passos.',
    agent=estrategista_chefe
)

# 3. Orquestração (A "Crew")
equipe = Crew(
    agents=[analista_financeiro, gestor_rh, estrategista_chefe],
    tasks=[tarefa_financas, tarefa_rh, tarefa_final],
    process=Process.sequential # Um trabalha após o outro
)

start_time_agente = time.time()

# Executa o fluxo de trabalho
resultado_multi_agente = equipe.kickoff()

end_time_agente = time.time()
latencia_agente = end_time_agente - start_time_agente

print(f"\n[Latência Multi-Agente]: {latencia_agente:.2f} segundos")
print(f"[Resposta Final do COO]:\n{resultado_multi_agente}")

```
